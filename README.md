Skyline Courier — fly the courier jet through the rings and put her down on runway 27. Three sorties: a ring run over the Coral Coast by day, an island hop through the ridge at dusk, and a storm courier run at night with gusting wind. Chase view over recognisable terrain, a lit glass-cockpit instrument bar (airspeed, altitude, heading, throttle, fuel, artificial horizon), fuel that turns every ring into a decision, and landings that read as landings — gentle on the strip, or a crash in the hills. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Arrow keys (or WASD) steer, Shift / Ctrl work the throttle, the mouse steers too, P pauses, M mutes, R restarts. Press 1, 2 or 3 to pick a sortie.
